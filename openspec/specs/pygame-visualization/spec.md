## Requirements
### Requirement: Simulation Frame Rendering
The Pygame renderer SHALL render the building structure, elevator shafts, passenger queues, and live performance metrics.

#### Scenario: Render frame output
- **WHEN** render is called on the environment
- **THEN** it draws the building floors, active elevators with load indicators, and the metrics dashboard
