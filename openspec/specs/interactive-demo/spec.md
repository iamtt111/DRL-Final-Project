## Requirements
### Requirement: Visual Interactive Demonstration
The demo script SHALL load a selected agent, connect it to the Pygame renderer, and run the simulator visually in real-time.

#### Scenario: Blinking emergency bed visualization
- **WHEN** Level 3 emergency occurs during the visual run
- **THEN** the screen renders a red blinking indicator and routes the nearest available elevator to it
